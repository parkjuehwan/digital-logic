Digital Logic from Zero

논리 게이트부터 7-Segment Counter까지

이 교재는 디지털 논리회로를 처음 배우는 사람을 위해 만들어졌습니다. AND, OR, Flip-Flop을 하나씩 외우는 대신, 처음부터 하나의 완성품을 목표로 정해 두고 거기에 필요한 개념을 차례대로 쌓아 갑니다.

CHAPTER 01

디지털 신호와 0 / 1

왜 배우나요? 7-Segment에 숫자를 띄우려면 회로가 "숫자"를 다룰 수 있어야 합니다. 그런데 회로 안에 흐르는 것은 숫자가 아니라 전압뿐입니다. 전압을 어떻게 숫자로 바꿔 읽는지가 모든 것의 출발점입니다.

아날로그와 디지털

아날로그(analog) 신호는 값이 연속적으로 변합니다. 볼륨 노브를 돌리면 소리가 0%, 0.1%, 0.11%, …처럼 끊김 없이 커지는 것과 같습니다. 반면 디지털(digital) 신호는 정해진 몇 개의 값만 사용합니다. 디지털 논리회로에서는 딱 두 가지 상태만 씁니다. 낮음(LOW)과 높음(HIGH)입니다.

디지털 신호는 "어느 정도 높은가"가 아니라 "높은가, 낮은가"만 따집니다.

전압을 0과 1로 읽기

회로의 전선에는 전압이 걸려 있습니다. 디지털 회로는 이 전압을 다음처럼 해석하기로 약속합니다.

전압 (예시)상태논리값
0 V 근처LOW0
5 V 근처HIGH1

핵심은 "근처"라는 말입니다. 실제 전선의 전압은 정확히 5.000V가 아니라 4.8V일 수도, 4.6V일 수도 있습니다. 하지만 디지털 회로는 "충분히 높으면 1, 충분히 낮으면 0"으로 읽기 때문에 작은 잡음(noise)이 있어도 값이 바뀌지 않습니다. 이것이 디지털이 아날로그보다 튼튼한 이유입니다.

구간 경계 숫자는 개념 설명용입니다. 실제 경계값은 부품 종류(TTL, CMOS 등)마다 다르지만, 입문 단계에서는 "낮으면 0, 높으면 1, 그 사이는 피한다"만 기억하면 충분합니다.

bit: 0 또는 1 하나

0 또는 1 하나를 담는 정보의 최소 단위를 bit(binary digit)라고 합니다. 전선 하나 = bit 하나라고 생각하면 됩니다. bit 하나로는 두 가지 상태(꺼짐/켜짐, 아니오/예)밖에 표현하지 못합니다.

그렇다면 0~9 같은 숫자는 어떻게 표현할까요? 전선을 여러 개 쓰면 됩니다. 전선 2개면 00, 01, 10, 11의 4가지, 전선 4개면 16가지 조합이 생깁니다. 이 조합에 숫자를 하나씩 대응시키는 규칙이 다음 챕터의 이진수입니다.

최종 회로와 연결

최종 회로의 모든 전선은 0 또는 1만 전달합니다. Clock의 박자, Counter의 4bit, 7-Segment의 a~g 신호까지 전부 "전압이 높은가 낮은가"일 뿐입니다.

CHAPTER 02

이진수 (Binary)

왜 배우나요? Counter는 "지금 몇 번째인가"를 bit 4개로 기억합니다. 0101이 왜 5인지 모르면 Counter도, Decoder도 이해할 수 없습니다.

십진수의 자리값부터 다시 보기

우리가 매일 쓰는 십진수 352는 사실 각 자리에 자리값을 곱해서 더한 것입니다.

352 = 3×100 + 5×10 + 2×1 = 3×10² + 5×10¹ + 2×10⁰

십진수는 숫자 10개(0~9)를 쓰고, 자리가 하나 올라갈 때마다 자리값이 10배가 됩니다. 이진수는 숫자 2개(0, 1)만 쓰고, 자리가 올라갈 때마다 자리값이 2배가 됩니다.

이진수 0101 = 0×8 + 1×4 + 0×2 + 1×1 = 0×2³ + 1×2² + 0×2¹ + 1×2⁰ = 5

CHAPTER 03

Boolean Logic

왜 배우나요? "숫자가 9이고 Clock이 들어오면 0으로 돌아가라", "숫자가 1이나 4가 아니면 segment a를 켜라" — 최종 회로가 하는 판단은 전부 0과 1에 대한 논리 연산입니다.

Boolean 논리(불 대수)는 0과 1, 두 값만 가지고 계산하는 수학입니다. 19세기 수학자 George Boole이 만들었고, 지금은 모든 디지털 회로의 언어가 되었습니다. 다음 세 가지 표현은 모두 같은 뜻입니다.

논리값참/거짓전압스위치
1True (참)HIGHON
0False (거짓)LOWOFF

그래서 "A이고 B이다"라는 문장 논리를 그대로 회로로 옮길 수 있습니다. 예를 들어 "문이 닫혀 있고(A) 시작 버튼이 눌렸으면(B) 전자레인지를 켠다(Q)"는 Q = A AND B입니다.

기본 연산 6가지

입력 A, B에 대해 출력 Q가 어떻게 정해지는지를 Truth Table(진리표)로 정리합니다. 진리표는 "가능한 모든 입력 조합"과 "그때의 출력"을 빠짐없이 적은 표입니다.

기호 정리
  • A̅ 또는 ¬A : NOT A
  • A · B 또는 AB : A AND B (곱셈처럼 생각하면 결과가 같습니다)
  • A + B : A OR B (단, 1 + 1 = 1)
  • A ⊕ B : A XOR B ("둘이 다르면 1")
최종 회로와 연결

Decoder가 "지금 숫자에서 segment a를 켤까?"를 결정하는 규칙, MOD-10 Counter가 "10이 됐나?"를 판단하는 규칙이 모두 이런 Boolean 식으로 쓰입니다.

CHAPTER 04

Logic Gates

왜 배우나요? Boolean 연산은 종이 위의 수학입니다. 그 수학을 실제 전기로 계산하는 부품이 Logic Gate입니다. 최종 회로는 결국 게이트 수십 개를 연결한 것입니다.

Logic Gate는 입력 전선의 전압(0/1)을 보고 출력 전선의 전압을 정하는 작은 회로입니다. 내부는 트랜지스터 몇 개로 되어 있지만, 우리는 안을 들여다볼 필요 없이 "입력이 이러면 출력은 이렇다"는 진리표만 알면 됩니다. 회로도에서는 게이트마다 정해진 모양의 기호를 씁니다.

작은 동그라미(○)의 의미 NAND와 NOR 기호 끝의 작은 동그라미는 "출력을 뒤집는다(NOT)"는 뜻입니다. NAND = AND + NOT, NOR = OR + NOT 입니다.

A, B 버튼을 눌러 입력을 바꿔 보세요. 초록색 전선은 1(HIGH), 회색 전선은 0(LOW)입니다. 진리표에서 현재 입력에 해당하는 행이 강조됩니다.

NAND 하나로 모든 것을 NAND 게이트만 여러 개 있으면 NOT, AND, OR 등 모든 게이트를 만들 수 있습니다(universal gate). 예를 들어 NAND의 두 입력을 묶으면 NOT이 됩니다. 실제 칩 설계에서 NAND가 특히 많이 쓰이는 이유입니다. 다음 챕터들의 Latch도 NAND나 NOR로 만듭니다.
최종 회로와 연결

BCD → 7-Segment Decoder의 내부는 AND/OR/NOT 게이트 덩어리이고, Counter 속 Flip-Flop도 게이트로 만들어집니다. 최종 회로의 모든 블록은 이 6가지 게이트로 분해할 수 있습니다.

CHAPTER 05

조합 논리회로 (Combinational Logic)

왜 배우나요? 게이트 하나로는 할 수 있는 일이 적습니다. 여러 게이트를 연결하면 "더하기", "숫자를 7-Segment 신호로 바꾸기" 같은 쓸모 있는 일을 할 수 있습니다.

여러 게이트를 연결해서 만든 회로 중, 다음 성질을 가진 것을 조합 논리회로라고 합니다.

현재 출력은 현재 입력에 의해서만 결정된다.

즉, 조합 논리회로는 기억이 없습니다. 같은 입력을 넣으면 언제나 같은 출력이 나옵니다. 1분 전에 무슨 입력이 들어왔었는지는 전혀 상관없습니다. 그래서 조합 논리회로는 진리표 하나로 완전히 설명할 수 있습니다.

예제: Half Adder (반가산기)

1bit 두 개를 더하는 회로입니다. 이진수 덧셈 규칙을 보면:

0 + 0 = 0 (자리올림 없음) 0 + 1 = 1 1 + 0 = 1 1 + 1 = 10 (결과 0, 자리올림 1)

결과 자리(Sum)와 자리올림(Carry)을 따로 보면, 이미 아는 게이트와 똑같습니다.

Sum = A ⊕ B (XOR: 둘이 다를 때 1) Carry = A · B (AND: 둘 다 1일 때 1)

미리 보기: Decoder도 조합 논리회로다

나중에 만들 BCD → 7-Segment Decoder도 정확히 같은 종류의 회로입니다. 입력은 4bit(BCD), 출력은 7개(a~g)일 뿐, "지금 입력이 0101이면 출력은 1011011"처럼 현재 입력만 보고 출력을 정합니다. Half Adder가 진리표 4줄짜리였다면, Decoder는 진리표 10줄짜리 조합 논리회로입니다.

최종 회로와 연결

최종 회로의 Decoder 블록이 바로 조합 논리회로입니다. 하지만 Counter는 다릅니다. "다음 숫자"를 만들려면 "지금 숫자"를 기억해야 하는데, 조합 논리회로에는 기억이 없습니다. 그래서 다음 챕터가 필요합니다.

CHAPTER 06

Memory의 시작: Latch

왜 배우나요? Counter는 "지금 3이니까 다음은 4"라고 판단해야 합니다. 그러려면 회로가 3이라는 사실을 기억하고 있어야 합니다. 회로가 기억을 갖는 첫 번째 방법이 Latch입니다.

기억의 비밀: 출력을 다시 입력으로 (Feedback)

NOR 게이트 두 개를 준비해서, 각 게이트의 출력을 상대 게이트의 입력으로 연결합니다(cross-coupling). 그러면 두 게이트가 서로의 상태를 계속 붙잡아 주는 고리가 생깁니다. 한 번 Q=1이 되면, 그 1이 다시 돌아와서 Q=1을 유지시킵니다. 이 회로를 SR Latch라고 합니다.

  • S (Set) = 1 → Q를 1로 만든다
  • R (Reset) = 1 → Q를 0으로 만든다
  • S = R = 0 → 아무것도 바꾸지 않는다 → 이전 값을 기억(Hold)

이 진리표에는 조합 논리에는 없던 것이 있습니다. 출력 칸에 "Q (이전 값)"이 들어 있다는 점입니다. 출력이 과거에 의존한다 — 이것이 순차 논리회로의 정의입니다.

NAND 두 개를 cross-coupling해도 같은 기억 회로를 만들 수 있습니다(이때는 입력이 0일 때 동작하는 S̅R̅ Latch가 됩니다). 중요한 것은 게이트 종류가 아니라 feedback 고리입니다.
최종 회로와 연결

Latch는 1bit를 기억합니다. Counter의 숫자 4bit를 기억하는 장치의 뿌리가 바로 이 feedback 구조입니다. 다만 Latch는 입력이 바뀌는 즉시 반응해서 "박자에 맞춰 한 칸씩" 움직이기 어렵습니다. 그 문제를 Flip-Flop이 해결합니다.

CHAPTER 07

Flip-Flop과 Clock

왜 배우나요? Counter는 "Clock이 한 번 칠 때 정확히 1만" 증가해야 합니다. 정해진 순간에만 값을 바꾸는 기억 장치가 Flip-Flop입니다.

Clock: 회로의 박자

Clock은 0과 1을 규칙적으로 반복하는 신호입니다. 오케스트라 지휘자의 지휘봉처럼, 회로 전체에 "지금!"이라는 타이밍을 알려 줍니다.

  • Rising Edge (상승 에지, ↑): Clock이 0 → 1로 올라가는 순간
  • Falling Edge (하강 에지, ↓): Clock이 1 → 0으로 내려가는 순간

Flip-Flop = Clock 에지에서만 바뀌는 1bit 기억 장치

Latch는 입력이 바뀌면 언제든 바로 반응합니다. Flip-Flop은 Latch를 개량해서 Clock 에지 순간에만 입력을 보고 값을 바꿉니다. 그 외의 시간에는 입력이 아무리 바뀌어도 값을 그대로 유지합니다. 덕분에 회로 전체가 박자에 맞춰 한 걸음씩 움직일 수 있습니다.

D Flip-Flop (Data)

Clock의 Rising Edge 순간에 입력 D의 값을 찍어서(sample) Q에 저장합니다. "사진 찍기"와 같습니다. 셔터(Clock ↑)를 누른 순간의 장면만 남습니다.

Clock ↑ 순간: Q(다음) = D 그 외 시간: Q 유지

D를 여러 번 바꿔 봐도 Q는 변하지 않습니다. Clock ↑을 누르는 순간에만 D 값이 Q로 복사됩니다.

T Flip-Flop (Toggle) — Counter의 주인공

T Flip-Flop은 더 단순합니다. T=1로 고정해 두면, Clock 에지가 올 때마다 Q가 뒤집힙니다(toggle).

Clock: ↑ ↑ ↑ ↑ ↑ Q: 0 → 1 → 0 → 1 → 0 → ...

전등 스위치를 "누를 때마다 켜짐/꺼짐이 바뀌는" 방식이라고 생각하면 됩니다. 흥미로운 점은, Q가 0→1→0으로 한 바퀴 도는 데 Clock이 2번 필요하다는 것입니다. 즉 Q는 Clock의 절반 속도로 깜빡입니다. 이 성질이 바로 다음 챕터 Counter의 비밀입니다.

JK Flip-Flop은? 교과서에는 JK Flip-Flop도 나옵니다. J=K=1로 두면 T Flip-Flop처럼 toggle하기 때문에, 실제 Counter IC 안에서는 JK나 D Flip-Flop으로 T 동작을 만드는 경우가 많습니다. 이번 교재에서는 개념이 가장 직관적인 T Flip-Flop으로 설명합니다.

CHAPTER 08

Binary Counter

왜 배우나요? 드디어 "숫자가 하나씩 올라가는" 회로를 만듭니다. 최종 회로의 심장입니다.

T Flip-Flop 4개를 이어 붙이면

Chapter 2의 이진수 표를 다시 보세요. 각 bit가 바뀌는 규칙이 있었습니다.

  • Q0 (자리값 1): Clock마다 toggle
  • Q1 (자리값 2): Q0이 1 → 0으로 떨어질 때 toggle (2번에 1번)
  • Q2 (자리값 4): Q1이 1 → 0으로 떨어질 때 toggle (4번에 1번)
  • Q3 (자리값 8): Q2가 1 → 0으로 떨어질 때 toggle (8번에 1번)

T Flip-Flop은 "Clock의 절반 속도로 깜빡인다"고 했죠. 그렇다면 첫 번째 Flip-Flop의 출력 Q0을 두 번째 Flip-Flop의 Clock으로 쓰면, 두 번째는 1/4 속도, 세 번째는 1/8 속도…로 깜빡입니다. 이것이 정확히 이진수가 1씩 증가하는 패턴입니다!

Clock ─▶ [T-FF] ─Q0─▶ [T-FF] ─Q1─▶ [T-FF] ─Q2─▶ [T-FF] ─Q3 (÷2) (÷4) (÷8) (÷16)

앞 Flip-Flop의 변화가 물결처럼 다음으로 전달된다고 해서 이런 구조를 Ripple Counter(비동기 카운터)라고 부릅니다. (모든 Flip-Flop이 같은 Clock을 받는 Synchronous Counter도 있는데, 결과로 나오는 숫자 순서는 같습니다.)

CHAPTER 09

MOD-10 Counter

왜 배우나요? 우리가 원하는 것은 0 → 1 → … → 9 → 0의 십진수 한 자리입니다. 4bit Counter를 9 다음에 0으로 돌아가게 고쳐야 합니다.

문제: 4bit Counter는 15까지 간다

4bit Counter: 0 → 1 → ... → 9 → 10 → 11 → ... → 15 → 0 우리가 원하는: 0 → 1 → ... → 9 → 0

해결: 10이 되는 순간 Reset

10의 이진수는 1010입니다. 0~9 중에는 Q3 = 1이면서 Q1 = 1인 숫자가 없습니다. (8=1000, 9=1001) 그러므로 "Q3 AND Q1"이 1이 되는 순간이 곧 10이 된 순간입니다.

CLEAR = Q3 · Q1 ← AND 게이트 하나!

이 CLEAR 신호를 모든 Flip-Flop의 Reset 단자에 연결하면, 10이 되자마자 모든 bit가 0이 됩니다.

9 1001 │ Clock ↑ 10 1010 ← Q3·Q1 = 1 감지! │ 즉시 Reset (아주 짧은 순간, 수 ns) 0 0000

1010 상태는 사람 눈으로 볼 수 없을 만큼 짧은 순간(수 나노초)만 존재합니다. 그래서 사용자 입장에서는 그냥 9 → 0으로 보입니다. Chapter 4에서 배운 AND 게이트 하나가 Counter의 성격을 바꿔 버린 것입니다.

이름: MOD-10 Counter / Decade Counter

10개의 상태(0~9)를 순환하므로 MOD-10 Counter(modulo 10), 십진수 한 자리를 세므로 Decade Counter라고 부릅니다. 실제 부품으로는 74HC90, 74HC160, CD4518 같은 IC가 있습니다.

참고: 비동기 Reset의 한계 여기서 설명한 "10이 되면 즉시 Reset" 방식은 원리가 직관적이라 입문용으로 좋지만, 아주 짧은 순간 1010이 생긴다는 단점(glitch)이 있습니다. 실제 설계에서는 9일 때 "다음 Clock에 0을 넣어라"라고 미리 준비하는 동기식(synchronous) 방식을 더 많이 씁니다. 결과로 보이는 숫자 순서는 같습니다.

최종 회로의 MOD-10 Counter 블록이 완성되었습니다. 이 블록은 Clock이 들어올 때마다 0~9를 4개의 전선으로 내보냅니다. 이 4bit의 이름이 다음 챕터의 BCD입니다.

CHAPTER 10

BCD (Binary Coded Decimal)

왜 배우나요? MOD-10 Counter가 내보내는 4bit는 평범한 이진수와 조금 다른 약속을 따릅니다. 그 약속이 BCD이고, Decoder는 BCD를 입력으로 받습니다.

BCD는 "십진수 한 자리(0~9)를 4bit 이진수로 적는 방법"입니다. 0~9 구간에서는 일반 이진수와 똑같이 생겼습니다.

4bit 값일반 Binary로 읽으면BCD로 읽으면

차이는 1010 ~ 1111입니다. 일반 이진수에서는 10~15를 뜻하지만, BCD에서는 사용하지 않는(invalid) 코드입니다. BCD 한 묶음(4bit)은 언제나 십진수 한 자리만 담기 때문입니다.

여러 자리 숫자에서의 차이

차이는 숫자가 두 자리 이상일 때 분명해집니다. 십진수 25를 표현해 보면:

일반 Binary: 25 = 11001 (숫자 전체를 한 번에 이진수로) BCD: 25 = 0010 0101 (자리마다 따로: 2 → 0010, 5 → 0101)

BCD는 bit를 조금 낭비하지만, 자리마다 바로 7-Segment 하나에 연결할 수 있어서 숫자 표시 장치에 아주 편리합니다.

CHAPTER 11

7-Segment Display

왜 배우나요? 회로 안의 0101은 사람이 읽기 어렵습니다. 숫자 모양으로 보여 주는 출력 장치가 필요합니다.

7-Segment Display는 막대 모양의 LED 7개(segment)로 숫자를 그리는 부품입니다. 각 segment에는 위에서부터 시계 방향으로 a ~ f, 가운데에 g라는 이름이 붙어 있습니다.

segment 이름

1 = ON, 0 = OFF (Common Cathode 기준)

7-Segment에는 LED의 (−)쪽을 공통으로 묶은 Common Cathode형과 (+)쪽을 묶은 Common Anode형이 있습니다. 이 교재는 Common Cathode를 기준으로 합니다. 이 경우 segment 핀에 1(HIGH)을 주면 켜지고, 0(LOW)을 주면 꺼집니다. (Common Anode는 반대로 0일 때 켜집니다.)

  • 입력: A, B, C, D (BCD 4bit)
  • 출력: a ~ g (7-Segment에 저항을 거쳐 연결)
  • 부가 기능: LT(Lamp Test, 모든 segment 켜기), BL(Blanking, 모두 끄기), LE(Latch Enable, 값 고정)
  • 1010 이상의 잘못된 BCD 입력이 들어오면 모든 segment를 끕니다(위 시뮬레이터도 같은 동작).

CHAPTER 13

Clock Generator

왜 배우나요? 지금까지 데모에서는 사람이 Clock 버튼을 눌렀습니다. 진짜 카운터는 스스로 1초마다 숫자를 바꿔야 합니다. 일정한 박자를 자동으로 만드는 회로가 필요합니다.

Square Wave (구형파)

Clock 신호는 HIGH와 LOW를 일정한 간격으로 반복하는 사각형 모양의 파형입니다.

점선은 Rising Edge(↑). Counter는 이 순간마다 1씩 증가합니다.

Frequency (주파수)

1초 동안 이 파형이 몇 번 반복되는지를 주파수(frequency)라고 하고, 단위는 Hz(헤르츠)입니다. 한 번 반복하는 데 걸리는 시간은 주기(period, T)입니다.

f = 1 / T 1 Hz → T = 1 초 (1초에 1번) 2 Hz → T = 0.5 초 (1초에 2번) 0.5 Hz → T = 2 초 (2초에 1번)

따라서 1Hz Clock을 MOD-10 Counter에 연결하면 약 1초마다 숫자가 하나씩 증가합니다. 참고로 컴퓨터 CPU의 Clock은 수 GHz, 즉 1초에 수십억 번입니다.

NE555 Timer로 Clock 만들기

실제 회로에서 가장 많이 쓰는 입문용 Clock 발생기는 NE555 Timer IC입니다. 555에 저항 2개와 커패시터 1개를 연결해 Astable(비안정) 모드로 동작시키면, 출력 핀에서 Square Wave가 계속 나옵니다. 커패시터가 충전·방전을 반복하면서 출력을 HIGH/LOW로 뒤집는 원리입니다. 저항이나 커패시터 값을 바꾸면 주파수가 바뀝니다.

555 주파수 공식 선택 · 심화

Astable 모드에서 저항 R1, R2와 커패시터 C를 쓰면 주파수는 대략 다음과 같습니다.

f ≈ 1.44 / ((R1 + 2·R2) · C)

예: R1 = 1kΩ, R2 = 68kΩ, C = 10µF → f ≈ 1.44 / (137,000 × 0.00001) ≈ 1.05 Hz (약 1초 주기)

내부 구조(비교기 2개, SR Latch, 방전 트랜지스터)는 이후 아날로그/전자회로 과목에서 다룹니다. 흥미롭게도 555 내부에도 Chapter 6의 SR Latch가 들어 있습니다.

더 정확한 시간이 필요하면 수정 발진자(Crystal Oscillator, 예: 32.768kHz)를 쓰고 Counter로 나누어 1Hz를 만듭니다. 손목시계가 이 방식입니다. T Flip-Flop 하나가 주파수를 절반으로 나눈다는 것(Chapter 7)을 떠올려 보세요. 32768 = 2¹⁵ 이므로 Flip-Flop 15개를 연결하면 정확히 1Hz가 됩니다.
최종 회로와 연결

Clock Generator는 최종 회로의 맨 앞에서 Counter에게 "지금 1 올려!"라는 신호를 1초마다 보냅니다. 이제 모든 블록이 준비되었습니다.

  4. Decoder(조합 논리회로)가 입력 0101을 보고 즉시 a=1 b=0 c=1 d=1 e=0 f=1 g=1을 출력합니다.
  5. 7-Segment의 a, c, d, f, g LED가 켜지고 화면에 5가 나타납니다.
  6. 다음 Rising Edge까지 Flip-Flop이 0101을 기억하고 있으므로 5가 계속 표시됩니다.

배운 개념최종 회로에서 쓰인 곳
01 전압과 0/1모든 전선이 HIGH/LOW로 정보를 전달
02 이진수Counter가 현재 숫자를 4bit로 표현

05 조합 논리회로BCD → 7-Segment Decoder 전체

08 Binary CounterFlip-Flop 4개를 이어 +1씩 증가
09 MOD-10 Counter9 다음에 0으로 돌아가기
10 BCDCounter와 Decoder 사이의 공통 언어

처음에 배운 작은 AND 게이트 하나, 1bit를 붙잡는 feedback 고리 하나가 쌓이고 연결되어 0 → 1 → 2 → … → 9 → 0을 끝없이 반복하는 장치가 되었습니다. 디지털 시스템은 아무리 복잡해 보여도 결국 이런 블록들의 조합입니다.

다음 단계로
  • 두 자리 카운터 (00~99): MOD-10 Counter의 9 → 0 순간을 다음 자리 Counter의 Clock으로 연결해 보세요(Carry).
  • 시계 만들기: 초는 MOD-60, 시는 MOD-24 (또는 12) Counter가 필요합니다.
  • Karnaugh Map: Decoder의 segment 식을 최소한의 게이트로 줄이는 방법.
  • 실제 제작: NE555 + 74HC90(또는 CD4518) + CD4511 + Common Cathode 7-Segment로 브레드보드에서 직접 만들 수 있습니다.
최종 회로 완성

Clock → Counter → BCD → Decoder → 7-Segment. 모든 블록이 연결되었습니다. 축하합니다!
